# Paleta Fullguete 3.0

Amostragem dos pixels sRGB totalmente opacos (alfa 255) dos dois PNGs oficiais. O degradê da marca contém vários tons próximos. Os valores abaixo ocorrem nos arquivos originais.

| Ativo | Pixels de referência |
|---|---|
| `assets/logo.png` (900 × 238) | Branco `#FFFFFF` (13.738 pixels), ciano `#00EBFD` (472), violeta `#9342FD` (16) |
| `assets/icone.png` (256 × 209) | Ciano `#00EBFD` (378), violeta `#9342FD` (12) e `#8B3EFB` (12) |

O ciano é o acento principal. O violeta claro `#C4A1FF` é um token derivado para séries e elementos decorativos. Superfícies quase pretas e uma faixa em tons escuros de violeta e ciano preservam a composição aprovada. Amarelo indica pendências.
